# Homebrew tap

```sh
brew install --cask padmk/tap/portside
```

[Portside](https://github.com/padmk/portside) keeps your local dev servers running, in one place: a menu bar app, a dashboard, a CLI and an MCP server for coding agents. It needs macOS 26 or later on Apple Silicon.

The cask is updated by Portside's release workflow; do not edit `Casks/portside.rb` by hand. Report problems in the [Portside repository](https://github.com/padmk/portside/issues).
